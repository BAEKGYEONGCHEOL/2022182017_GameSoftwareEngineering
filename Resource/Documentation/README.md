# Dark Sci-Fi Modular Blender Asset Pack

- Blender 5.2 authoring source, metric units, +Z up, -Y forward.
- Low-poly modular humanoid uses a 7-head heroic proportion and HUM_v1 shared skeleton.
- Void quadruped is an original low-center, four-legged assault creature with VOID_v1 modular overlays.
- Ship walls and floor tiles use a 2 m module and 0.25 m snap grid.
- Materials use dark gunmetal, oxidized armor, cold cyan displays, warning amber, desaturated skin and violet-red alien tissue.
- Animation clips include walk, run, left/right turn, attack, jump, turn interpolation poses, and walk/run transitions.

## Libraries

- `DarkSciFi_ModularAssetPack.blend`: complete source and showcase scene.
- `Libraries/Humanoid_Modular.blend`: human rig, body parts, clothing, equipment, actions.
- `Libraries/Void_Quadruped.blend`: quadruped rig, modular parts, actions.
- `Libraries/Ship_ModularKit.blend`: walls, controls, medical devices, floor tiles/materials.
- `Libraries/Space_Asteroids.blend`: four low-poly asteroids and drift-spin actions.

See `AnimationAndAssembly.json` for clip mapping and blend recommendations.
